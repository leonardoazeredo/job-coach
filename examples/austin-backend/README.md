# Dana Okafor (fictional)

A made-up senior backend engineer in Austin, Texas, working in USD. Every name, company, email address, phone number and metric here is invented; the employers do not exist.

The folders follow the layout of a real repo. `pipeline/` holds three roles at different statuses; `larkspur-backend-engineer` also has a role CV. The tests copy everything except the role folders into a temp repo (`scripts/__tests__/temp-repo.ts`), so changing a file here can change what the tests see.
